# Deprecated: `epoxy_style()`

`epoxy_style()` was renamed
[`epoxy_transform()`](http:/pkg.garrickadenbuie.com/epoxy/preview/pr132/reference/epoxy_transform.md)
in epoxy version 0.1.0.

## Usage

``` r
epoxy_style(...)

epoxy_style_apply(...)

epoxy_style_bold(...)

epoxy_style_code(...)

epoxy_style_collapse(...)

epoxy_style_get(...)

epoxy_style_html(...)

epoxy_style_inline(...)

epoxy_style_italic(...)

epoxy_style_set(...)

epoxy_style_wrap(...)
```

## Arguments

- ...:

  Passed to the new `epoxy_transform` function.

## Value

Returns the result of the new `epoxy_transform` function.
