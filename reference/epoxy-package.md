# epoxy: String Interpolation for Documents, Reports and Apps

Extra strength 'glue' for data-driven templates. String interpolation
for 'Shiny' apps or 'R Markdown' and 'knitr'-powered 'Quarto' documents,
built on the 'glue' and 'whisker' packages.
